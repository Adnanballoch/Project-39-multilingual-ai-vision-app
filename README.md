# Project 39: Multilingual AI Vision App: Reading and Replying in the Same Language

**Category:** EdTech / AI Infrastructure
**Part of:** AutoMatrixLab

## Overview

An AI application capable of reading chats in multiple languages and replying instantly in the same language: English, Chinese, Hindi, or Māori.

## Tech Stack

NVIDIA RTX 4070 Super, Local LLM, OpenAI, Azure TTS/STT
